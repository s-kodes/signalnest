# SignalNest

SignalNest is a personal engineering learning hub that helps me discover, filter, and organize technical content from different sources in one place.

## Goals

- Centralize engineering articles and newsletters.
- Filter content by topic and relevance.
- Identify potentially paywalled articles before opening them.
- Build a consistent technical reading habit.
- Practise software engineering and SRE skills by building and operating the application.
